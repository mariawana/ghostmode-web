# GhostMode

A browser-based invisibility experience using your webcam and real-time AI-powered image segmentation.

## 🌐 Live Demo

[**Try GhostMode Here**](https://ghostmode-web.vercel.app/)

## ✨ Features

- Real-time webcam access
- Background capture
- Invisibility effect
- Hand gesture detection
- Pinch gesture to toggle invisibility
- Screenshot capture
- Responsive user interface

## 🛠️ Built With

- React
- Vite
- JavaScript
- MediaPipe Tasks Vision
- CSS

## 🚀 Run Locally

1. Clone the repository:

   ```bash
   git clone https://github.com/mariawana/ghostmode-web.git
   ```

2. Navigate to the project folder:

   ```bash
   cd ghostmode-web
   ```

3. Install dependencies:

   ```bash
   npm install
   ```

4. Start the development server:

   ```bash
   npm run dev
   ```

5. Open the local URL provided by Vite.

## 📸 Requirements

- Webcam or built-in camera
- Modern web browser
- Camera permission enabled
